点击页面中的打开按钮，进入 ChatGPT 登录页面，使用需要开通 Plus 的账号登录。

- 左侧或账户菜单显示的邮箱是否正确
- 当前登录的是否为个人账号
- 是否正在使用正确的浏览器窗口
- 是否有多个 ChatGPT 标签页混在一起

1. 必须先在同一个浏览器完成 ChatGPT 登录。
2. 再打开平台教程中指定的会话页面。
3. 使用全选和复制，提交完整内容。
4. 不要手动删改 JSON 字段。
5. 不要把这段内容发给客服、朋友或公开发布。

## 优惠码 ACCPAY 怎么看

你提供的推广链接中包含 `ACCPAY` 参数。它可以用于进入对应推广入口，但不能仅凭 URL 判断具体优惠金额、适用套餐或有效期限。

优惠是否生效，要看以下位置：

- 注册或订阅页面是否显示优惠信息
- 订单详情是否出现折扣
- 收银台最终金额是否减少
- 优惠是否仅限新用户
- 是否只适用于首单或特定套餐
- 多月套餐和续费订单是否适用

不要因为页面入口带有优惠码，就默认所有套餐都会自动减价。不同优惠码可能只对注册、首单或指定产品生效。付款前如果结算金额没有变化，应以实际显示为准，不要把宣传页面中的参考价格当成已生效折扣。

## 多月套餐便宜，但要看清续费规则

长期套餐一般会降低平均每月成本，但同时也会增加退款和取消的复杂度。

BeWild 的帮助中心说明，长期订阅可能按照月份连续处理，用户不应在 ChatGPT 官方页面随意取消订阅，否则可能影响预付月份的继续使用。

购买多月套餐前，重点确认三件事：

1. 总共购买几个月。
2. 费用是一次性支付，还是按月继续扣款。
3. 取消操作会不会让剩余月份失效。

如果只是第一次使用，单月套餐更容易核对流程。已经确认账号稳定、确实需要长期使用，再考虑 2 个月或 3 个月方案。

## 充值失败、没有到账怎么办

### 已付款，但订单没有出现

帮助中心提到，微信已扣款但平台暂时没有订单，可能与海外支付通道回调延迟有关。建议等待一段时间后再到订单页面查看，不要马上重复付款。

联系客服时准备：

- 支付截图
- 扣款时间
- 支付金额
- 使用的邮箱
- 页面是否显示订单
- 是否收到支付成功通知

### 订单显示完成，但账号还是 Free

先重新登录 ChatGPT，刷新页面并检查账户菜单中的套餐状态。如果仍显示 Free，保存订单页面和 ChatGPT 账单页面截图，再联系客服核对。

不要先重新购买第二笔订单。否则客服需要同时判断两笔订单的状态，处理时间通常更长。

### 提交信息时报错

常见原因包括：

- 登录状态已经过期
- 提交的 JSON 不完整
- 使用了不同浏览器或不同账号
- 浏览器插件修改了页面内容
- 网络环境发生变化
- 账号本身无法完成升级

可以重新登录目标账号，再从同一浏览器重新获取信息。连续失败时先停止尝试，避免重复创建订单。

### 订阅成功后想退款

已完成履约、权益已经生效的订单，因选错套餐、误操作或购买后不想使用，通常不属于自动退款范围。仍在处理、尚未生效或部分多月月份未生效的订单，可以联系客服核实，但不能提前保证一定退款。

因此，付款前核对账号、套餐和周期，比付款后申请退款更重要。
